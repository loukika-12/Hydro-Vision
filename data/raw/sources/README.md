# Source data directory

Place original, unmodified dataset downloads here. This directory is intentionally
not populated with generated or fabricated observations. Do not commit API tokens,
credentials, or large source exports unless redistribution terms explicitly permit it.

Expected files:
- rainfall_india.csv (Kaggle download)
- groundwater_cgwb.csv (CGWB export, normalized column names only)
- reservoir_cwc.csv (CWC export, normalized column names only)

See docs/REAL_DATA_INTEGRATION.md for acquisition, schema, units, and matching rules.
